# Quirebase repository guidance

## Agent skills

### Issue tracker

Implementation work is tracked as local Markdown under `.scratch/<feature>/`.
See `docs/agents/issue-tracker.md`.

### Triage labels

Use the canonical `needs-triage`, `needs-info`, `ready-for-agent`,
`ready-for-human`, and `wontfix` states.
See `docs/agents/triage-labels.md`.

### Domain docs

Quirebase uses a single root `CONTEXT.md` and repository-wide decisions in
`docs/adr/`.
See `docs/agents/domain.md`.
