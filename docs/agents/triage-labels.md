# Triage Labels

Use these labels for issue triage:

| Label | Meaning |
| --- | --- |
| `needs-triage` | Maintainer evaluation needed |
| `needs-info` | Waiting for information from the reporter |
| `ready-for-agent` | Specified sufficiently for autonomous implementation |
| `ready-for-human` | Requires human implementation |
| `wontfix` | Closed without implementation |
