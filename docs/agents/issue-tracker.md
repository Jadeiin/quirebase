# Issue tracker: Local Markdown

Quirebase engineering work is recorded under `.scratch/`.

## Layout

- One feature per directory: `.scratch/<feature-slug>/`
- Feature description: `.scratch/<feature-slug>/PRD.md`
- Work items: `.scratch/<feature-slug>/issues/<NN>-<slug>.md`
- Each work item contains a `Status:` field
- Conversation and review notes are appended under `## Comments`

Do not create or update remote GitHub Issues unless explicitly requested.
