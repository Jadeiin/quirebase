# Source policy

Implementation inputs may include the GPLv3 PHP source tree, public standards, upstream dependency documentation, and independently written product requirements.

Commercial binary analysis, decompiled output, extracted symbols, strings, routes, SQL, identifiers, and internal structure are prohibited implementation inputs. Contributors must describe the public or GPL source for behavior-affecting changes in their pull request.

The Quirebase name, package identifiers, CLI, interface text, and visual system must remain independent from legacy branding.
