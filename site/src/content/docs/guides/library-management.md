---
title: Find and organize your Library
description: Search saved Items, combine filters, keep useful views, and organize Tags and Projects.
---

Open **Library** inside the Workspace you want to search. Library Search covers saved Item metadata
and extracted local PDF text. To search an external scholarly source, use [Discovery](/guides/discovery/).

## Find a saved reference

1. Enter a title fragment, author, Tag, or text phrase in **Library Search**.
2. Expand **Filters** if you want to choose a Tag, Project, file presence, year, Contributor, or keyword.
3. Choose **Search** to apply the form values.
4. Check the active filter labels above the results. Use **Clear filters** when a previous restriction
   is hiding the Item you expect.
5. Change the sort and page size as needed, then open an Item or its preview.

For example, to find references that still need PDFs, choose **Files → Without files**, then Search.
To review a working set, choose its Project. Filters narrow the same result set. Selecting several
exact author filters returns Items matching all those authors.

**Check the result:** the result count and visible active filters match the task. If you arrived via
**View imported Items**, the Library may still be restricted to that Import Batch. A different
Workspace also has a different Library.

## Save a useful view

1. Apply the filters, sort order, and page size you want to reuse.
2. Open **Saved views**, enter a name such as `Needs PDFs`, and choose **Save current view**.
3. Later, open **Saved views** and select its name to run those settings again.

A view stores filters, sort order, and page size, then runs that query when opened. Views are saved
in this browser for the current account and Workspace.

## Read or edit one Item

Open the Item and choose the section for the task:

| Section | Use it to |
| --- | --- |
| Overview | Read the bibliographic summary and open Item actions |
| Metadata | Correct the title, ordered Contributors, identifiers, Reference Type, date, and Citation Key |
| Files | Add or read PDF revisions and supplementary Attachments |
| Organize | Maintain Tags and Project associations |
| Annotations | Review visible marks and Replies associated with the Item |
| Discussion | Discuss the reference with authorized Workspace members |

Save metadata edits and check the returned result. If the Item changed concurrently, reload the
latest state, review it, and retry the intended edit. **Record tools → Metadata sources** offers
identifier-based updates; review the resulting metadata after updating.

## Assign Tags and Projects

In **Organize**, enter a Tag name and use **Add tag**, or use the available Tag controls to change an
assignment. Tags are shared Workspace taxonomy. Select a Provider keyword or Tag Recommendation
to assign it to the Item.

In the same section, find the Project and choose **Add**. The Item should then show that association
and be discoverable in the Project working set. **Remove** detaches the Item and permanently deletes
that association's Project Annotations and Replies.

For several Items, select the intended Library rows and choose a bulk action. **Select this page**
selects the current page. Check the selected count before making a change or exporting.

## Review duplicate suggestions

Open **Tools → Duplicate review**, choose **Shared identifier**, **Same title**, or **Same PDF**, and
run **Check for duplicates**. Title comparison uses exact values, including case and formatting;
PDF checks use ready files and may skip older files. Compare metadata, files, Project context, and
Annotations before retaining or deleting a record.

## Copy an Item into another Workspace

Open **Copy to Workspace**, choose an available destination, and choose **Create copy**. Use **Open
copy** to verify the new Item and its files in the destination.

Copying requires export permission in the source and Item creation permission in the destination.
Maintain the copy as an independent record in the destination Workspace.

Continue with [citations and exports](/guides/citations-and-exports/) when your selected references
are ready for writing.
