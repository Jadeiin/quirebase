---
title: Organize references with Tags
description: Assign Tags to references, browse a topic, and keep the Workspace's shared vocabulary consistent.
---

Use Tags for categories that span several reading Projects, such as `Methods`, `Datasets`, or
`To read`. Start in the Workspace containing the references you want to organize.

## Label a reference

1. Open the Item and choose **Organize**.
2. In **Tag matrix**, find an existing Tag. Use **Filter Tags** to narrow the list, then select its name.
3. To introduce a new label, enter its name under **Item Tags** and choose **Add tag**.
4. Check **Item Tags** to see the assigned labels.

For example, add `To read` to a newly imported reference. After reading it, select the label's
**×** under **Item Tags** to remove that assignment. The label remains available for other references.

New Tag names can contain 1–120 characters. Quirebase tidies whitespace and reuses an existing name
when only capitalization differs. Agree on a few useful labels with your colleagues so the shared
catalog stays easy to browse.

## Use recommendations while organizing

**Tag Recommendations** suggests names from the reference's metadata and latest ready PDF.
Select a **+** suggestion to assign it to the Item. A **★** beside a name in **Tag matrix** marks a
recommended existing Tag; select the name to apply it.

After updating metadata or adding a PDF, choose **Refresh** in **Tag Recommendations** to request
fresh suggestions. Review the suggestions when processing finishes and select the useful ones.

## Find all references with a Tag

1. Open **Tools → Tags**.
2. Enter part of the name in **Filter Tags**.
3. Find the label and choose **View Items**.
4. In Library, check the active Tag filter and open the matching references.

Combine the Tag with a Project, year, or file filter to narrow the result. For a recurring task,
[save the Library view](/guides/library-management/#save-a-useful-view).

## Rename a shared label

In **Tools → Tags**, choose **Rename** beside the label, enter the **New Tag name**, and confirm
**Rename**. The updated name appears on every assigned Item in the Workspace.

If the intended name already exists, use a merge to bring the two sets of assignments together.

## Merge two labels

For example, your team has used both `ML` and `Machine learning` and wants to keep `Machine learning`.
In **Tools → Tags**, find **Merge Tags**:

1. Set **Source Tag** to `ML`, the label you want to retire.
2. Set **Target Tag** to `Machine learning`, the label you want to keep.
3. Check the direction, then choose **Merge Tags**. This applies the merge immediately.
4. Find `Machine learning` and choose **View Items** to review the combined set.

The target receives every source assignment, including references already carrying both labels.
The source label is deleted. Update saved views that used the source Tag to use the target.

## Retire an unused label

Choose **Delete** beside a Tag in **Tools → Tags**, review its name, and confirm **Delete Tag**.
This deletes the shared label and its Item assignments throughout the Workspace. The references
remain in Library. To clear a label from just one reference, use **Item Tags → ×** on that Item.
