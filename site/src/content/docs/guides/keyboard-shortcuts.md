---
title: Navigate and organize with the keyboard
description: Switch pages and Workspaces, browse Library, select Items, and copy citations.
---

Open a Workspace's **Library**. Use Quick navigation to switch locations, then browse and select
references from the results list or preview. `Mod` means ⌘ Command on macOS and Ctrl on Windows
and Linux.

## Jump to a page, Workspace, or Project

1. Choose **Quick navigation**, or click a blank area of Library and press `Mod+K`.
2. Enter a name in **Search pages, Workspaces, or Projects**, such as `Projects` or a Workspace name.
3. Use `↓` and `↑` to choose a result and `Enter` to open it, or click the result.

For a reference keyword, choose **Search Library for …** to open the current Workspace's results.
Opening another Workspace switches Library and Projects to that Workspace.

## Open the Library shortcut reference

Choose the keyboard button beside the Library heading, or press `?`, to open **Keyboard shortcuts**.
**Enable letter and symbol shortcuts** controls keys such as `/`, `?`, `J`, `K`, `X`, and `I`.
This preference is saved for your account in the current browser.

| Key | Action |
| --- | --- |
| `/` | Focus Library Search |
| `?` | Open the shortcut reference |
| `Esc` | Close the current popup or preview; press again to clear Item selection |
| `Mod+Shift+C` | Open citation copying for the selected or current Items |

## Browse and select results

Use `Tab` to focus an Item's checkbox, then use these keys:

| Key | Action |
| --- | --- |
| `↑` / `K` | Move to the previous Item |
| `↓` / `J` | Move to the next Item |
| `Home` / `End` | Move to the first or last Item on this page |
| `Space` / `X` | Select or unselect the current Item |
| `Shift+X` | Select the current Item alone |
| `Shift+↑` / `Shift+↓` | Extend the selection upward or downward |
| `Mod+A` | Select this page |
| `I` / `Enter` | Open a preview from the Item's checkbox |
| `Shift+F10` | Open the current Item's action menu |

Press `Enter` on a title link to open Item details. With a mouse, Shift-click checkboxes to select
a range on the current page.

## Preview a sequence of references

After opening a preview, keep focus in the preview and use `↑` / `K` and `↓` / `J` to browse.
Preview navigation continues across pages in the current results; row navigation moves within the
current page. Use `Shift+F10` for the previewed Item's actions and `Esc` to return to the list.

## Try it: select references and copy citations

1. Search for a set of references to organize.
2. Use `Tab` to focus the first target checkbox and press `X` to select it.
3. Move with `↓` and select more with `X`, or use `Shift+↓` for a continuous range.
4. Keep focus on a selected Item and press `Mod+Shift+C`. Review the Items and format in the copy action.
5. Paste the copied result into your writing tool.

See [exports](/guides/citations-and-exports/) for citation formats and defaults.
