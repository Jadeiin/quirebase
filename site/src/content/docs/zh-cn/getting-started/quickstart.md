如果团队已经部署 Quirebase，请向管理员获取应用地址和用户账号或实例邀请。
需要自行运行实例时，先阅读[部署指南](/zh-cn/administration/deployment/)。

## 选择工作空间

登录后，打开 **My workspaces（我的工作空间）**，或通过工作空间菜单切换。
新用户创建时会获得一个普通 Workspace（工作空间）。加入已有团队，需要使用现有账号接受单独的工作空间邀请。

当前工作空间决定可见的 Item（条目）、标签、项目及可用操作。如果无法导入，请联系工作空间管理者确认角色。

## 导入第一条文献

1. 打开 **Import（导入）**，选择 **Identifiers（标识符）**。
2. 每行输入一个 DOI 或其他支持的标识符，例如 `10.1073/pnas.92.6.2288`。
3. 保持 **Auto detect（自动检测）**，生成预览。
4. 检查候选记录和诊断信息，确认需要导入的条目。
5. 在 **Library（资料库）** 中打开导入的条目，检查元数据。

准备预览不会创建条目，确认后才会写入资料库。也可以[导入书目文件或 PDF](/zh-cn/guides/import/)。

## 阅读和批注 PDF

在条目的 **Files（文件）** 中上传主 PDF，等待处理完成后打开阅读器。
每次上传的主 PDF 都是一个独立的 File Revision（文件修订版）。

在 **Annotations → Save new annotations to** 中选择 **Private annotations**，即可记录私人批注。
需要共享时，先将条目加入项目，再将新批注的保存目标设为该项目。
显示哪些批注来源与新批注保存到哪里，是两个独立的设置。

批注绑定具体文件修订版，不会随新 PDF 自动迁移。离开页面前检查保存状态。
更多说明见 [PDF 批注指南](/zh-cn/guides/pdf-annotations/)。

## 整理与协作

标签用于工作空间内的主题分类，Project（项目）用于组织协作中的条目集合。
同一条目可以加入同一工作空间内的多个项目，无需重复导入。

项目参与关系不会额外授予条目访问权限。邀请他人或共享资料前，请先阅读
[工作空间、项目与访问权限](/zh-cn/concepts/workspaces-and-projects/)。
