---
title: 添加第一条文献
description: 选择工作区，保存一条文献，上传 PDF，创建私人批注并核对结果。
---

本教程从“你已经能登录某个 Quirebase 实例”开始。请向实例管理员获取应用地址、账号或账号邀请。
如果需要自己运行实例，先完成[部署指南](/zh-cn/administration/deployment/)。

完成后，你会在一个工作区中得到一条文献记录、一份主 PDF 和一条私人批注。请准备一份有权上传的 PDF。
本文以当前中文界面为准，关键入口同时给出英文名称。

## 1. 选择文献要保存到的工作区

1. 登录后打开“我的工作区”（My workspaces），也可以用应用侧栏的工作区菜单切换。
2. 打开准备保存文献的工作区，先核对名称，再开始导入。
3. 进入“导入”，确认能看到导入方式标签。若没有这些入口，请联系工作区所有者或管理员确认你是否能创建条目。

新建账号通常会获得一个普通工作区。加入团队已有的工作区，需要以被邀请的用户身份接受另一份“工作区邀请”。
创建账号的邀请不会自动把你加入团队工作区。

## 2. 用 DOI 查找并确认导入

1. 打开“导入 → 标识符列表”（Import → Identifiers）。
2. 粘贴 `10.1073/pnas.92.6.2288`，“数据来源”保持“自动检测”。
3. 点击“预览元数据”。此时得到的是导入预览，文献库中还没有创建条目。
4. 检查标题、贡献者、出版信息和导入问题。预览中的“已识别的文献”会在确认时整批导入。
5. 点击预览底部的“导入 … 条记录”。
6. 出现“导入完成”后，点击“查看已导入文献”。

**核对结果：** 文献库中出现这条记录，且仍位于你刚才选择的工作区。打开“元数据”检查内容。
如果导入成功但页面没有自动跳转，继续使用“查看已导入文献”，无需重新提交一批导入。

如果在线查找暂不可用，可以打开“导入 → 手工创建”，填写标题和已知的文献信息，再点击“创建条目”。
手工创建会直接保存条目，没有导入批次预览。更多方式见[导入文献](/zh-cn/guides/import/)。

## 3. 上传并打开 PDF

1. 打开刚保存的条目，切换到“文件”。
2. 在“添加 PDF 修订”区域选择 PDF，点击“上传 PDF”。
3. 等待处理就绪后，在该文件旁点击“阅读”。

**核对结果：** 阅读器打开了预期的文档。一直等待时，请让运维人员检查独立的 Worker 进程；
处理失败时使用页面上的“重试处理”，或上传修正后的 PDF。详见[文件管理](/zh-cn/guides/files/)。

## 4. 创建并确认保存一条私人批注

1. 在阅读器中打开“批注”。
2. 在“新批注保存到”下面选择“私人批注”。
3. 使用批注工具标记一段文字或添加笔记。
4. 等待保存状态确认成功，再离开阅读器。
5. 重新打开**同一份 PDF 修订版**，并确保“显示的批注来源”中勾选了“私人批注”。

**核对结果：** 重新打开后仍能看到批注。如果页面报告保存失败，请先处理错误，再刷新。
上传另一份 PDF 不会把原有批注迁移过去。

## 5. 继续整理、协作或写作

- 用[标签、筛选和已保存视图](/zh-cn/guides/library-management/)整理文献库。
- [创建项目并共享批注](/zh-cn/guides/collaboration/)，与同事共读。
- 写作时[导出引文或书目](/zh-cn/guides/citations-and-exports/)。

同一条目可以加入本工作区中的多个项目。项目参与不会额外授予条目的操作权限。
要创建共享批注，必须先把“新批注保存到”设为项目；仅显示项目已有的批注，不会改变新批注的保存位置。
