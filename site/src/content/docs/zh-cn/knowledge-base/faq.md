title: 常见问题
description: 回答导入、私人笔记、项目可见性、PDF 修订版和导出边界中的常见困惑。
---

## 已经看到导入预览，为什么文献库中没有条目？

准备预览只创建候选记录。检查后点击“导入 … 条记录”，完成后使用“查看已导入文献”，并核对目标工作区。
手工创建不同：点击“创建条目”会直接保存。详见[导入指南](/zh-cn/guides/import/)。

## 预览里的哪些记录可以选择？

已识别记录会整批提交。“未识别元数据的 PDF”中的基础候选需要明确勾选，未选中的会跳过。
如果已识别批次不是你想要的内容，应丢弃后修正输入。确认数量的规则见[导入预览](/zh-cn/guides/import/)。

## 托管项目会把里面的文献变成私有吗？

托管模式限制项目协作上下文的可发现性，原始条目仍遵循工作区权限。
项目参与不额外授予条目权限。需要不同成员边界时，应使用不同工作区；跨工作区复制会创建独立记录。

## 查看者为什么可以创建私人笔记？

私人批注属于其作者。活跃工作区中的五种角色都可以维护自己的私人笔记；创建项目共享批注使用另一项授权。
详见[角色说明](/zh-cn/administration/workspaces-and-members/)。

## 实例管理员可以读取我的私人笔记吗？

实例管理不会自动获得工作区内容访问权，私人批注仍受作者范围限制。
有理由的一次性只读检查和所有权重新指派是显式、带审计的治理操作，不是一般浏览权限。
详见[访问概念](/zh-cn/concepts/workspaces-and-projects/)。

## 同事看不到我的标记，要检查什么？

先确认打开的是同一份 PDF 修订版。标记创建时，“新批注保存到”需要选择项目；同事还需要勾选该项目作为显示来源，并有相应访问权限。
仅显示项目已有标记，不会把新建的私人批注变成共享批注。操作见 [PDF 批注](/zh-cn/guides/pdf-annotations/)。

## 上传新的 PDF 后，批注会跟过去吗？

不会自动迁移。每个标记绑定一份修订版的具体页面，需要旧批注时应保留旧修订版。
导出会创建副本，不修改保存的原文件。

## 可以使用扫描 PDF 或加密 PDF 吗？

当前不支持 OCR 和加密 PDF。纯扫描图片 PDF 可能能显示，但没有可搜索的提取文本。
也不支持扁平化批注导出。

## 删除导入历史会删掉导入的文献吗？

删除或清理已提交批次会保留条目和文件，但不再保留确认结果及相应文献库筛选。
导入历史不是源文件备份。

## 离开工作区会删除什么？

离开会终止成员关系并清除显式项目选择，保留内容和作者记录。
重新加入需要新邀请，不会恢复以前的项目选择。所有者需要先转移所有权，才能离开。

## 换设备后，已保存视图和导出偏好为什么不同？

它们是浏览器本地偏好，区分账号，并在适用时区分工作区，不是同步到服务器的研究内容。
请重新核对当前浏览器设置。

## 书目导出可以当备份吗？

书目文件用于交换文献元数据，不能代替包含成员关系、讨论和文件的数据库与对象备份。
请按[备份恢复指南](/zh-cn/administration/maintenance/)操作。

## 程序或智能体怎样认证？

用有有效期的 API 令牌连接 [HTTP API](/zh-cn/developers/http-api/) 或 [MCP](/zh-cn/developers/mcp/)。
令牌沿用用户当前权限。运行实例的 `/docs` 和 `/openapi.json` 对应该版本；静态 API 参考保留 Schema 的英文描述。
