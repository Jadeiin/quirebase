## 已经看到导入预览，为什么文献库中没有条目？

检查预览后点击“导入 … 条记录”，完成后使用“查看已导入文献”打开结果，并核对目标工作区。
完整步骤见[导入指南](/zh-cn/guides/import/)。

## 预览里的哪些记录可以选择？

已识别记录会整批提交。“未识别元数据的 PDF”中，勾选要保留的基础候选。
调整批次和确认数量的步骤见[导入预览](/zh-cn/guides/import/)。

## 怎样为不同团队安排文献访问？

为成员范围不同的团队建立各自的工作区，并分配相应角色。
同一工作区内，用项目组织读书组和协作文献。详见[工作区与项目](/zh-cn/concepts/workspaces-and-projects/)。

## 阅读和评审分别选择什么角色？

查看者适合阅读、导出和记录私人笔记；评审者还可以参与项目共享批注、回复与讨论。
更多角色见[成员管理](/zh-cn/administration/workspaces-and-members/)。

## 谁能看到我的批注？

私人批注由本人查看；项目批注共享给具有阅读权限的项目参与者。
创建时，在“新批注保存到”中选择私人批注或目标项目。

## 同事看不到我的标记，要检查什么？

两人打开同一份 PDF 修订版，核对标记创建时的保存项目，并让同事在“显示的批注来源”中勾选该项目。
完整步骤见 [PDF 批注](/zh-cn/guides/pdf-annotations/)。

## 怎样查看旧 PDF 上的批注？

在条目的“文件”中找到原来的 PDF 修订版，点击“阅读”，再勾选相应的批注来源。
每份修订版保存自己的批注，保留旧修订版即可继续查看。

## 阅读和搜索对 PDF 有什么要求？

上传已解除加密的 PDF。扫描件可用于阅读；需要搜索正文时，准备带有文本层的 PDF。
文件准备和处理状态见[文件管理](/zh-cn/guides/files/)。

## 删除导入历史会删掉导入的文献吗？

删除或清理已提交批次会保留条目和文件，但不再保留确认结果及相应文献库筛选。

## 离开工作区会删除什么？

离开会终止成员关系并清除显式项目选择，保留内容和作者记录。
重新加入时接受新邀请，并重新安排项目参与。所有者先转移所有权，再离开工作区。

## 换设备后，已保存视图和导出偏好为什么不同？

这些偏好保存在当前浏览器中，按账号和工作区区分。使用新设备时，可重新设置所需的视图和导出默认值。

## 怎样备份整个实例？

由运维人员按[备份恢复指南](/zh-cn/administration/maintenance/)备份数据库与对象文件，保留成员关系、文献、讨论和文件。

## 程序或智能体怎样认证？

用有有效期的 API 令牌连接 [HTTP API](/zh-cn/developers/http-api/) 或 [MCP](/zh-cn/developers/mcp/)。
令牌沿用用户当前权限。运行实例的 `/docs` 和 `/openapi.json` 对应该版本；静态 API 参考保留 Schema 的英文描述。
