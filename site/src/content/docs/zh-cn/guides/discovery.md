title: 搜索外部来源
description: 在“发现”中构造查询、检查候选记录，再把选中的结果送入导入预览。

知道主题、标题或作者，想在线寻找文献时，使用“发现”（Discovery）。
查找 Quirebase 中已经保存的内容，应使用[文献库搜索](/zh-cn/guides/library-management/)。
发现结果只有在完成导入确认后，才会成为文献库中的条目。

## 开始前先确认工作区和来源

先选择文献准备保存到的工作区。搜索和导入都使用当前工作区权限。
可用来源、字段及排序方式取决于实例配置和各来源的能力；没有可选来源时，请联系运维人员检查来源配置。

## 先运行一个简单查询

1. 打开“发现”，选择一个“来源”（Provider）。
2. 在第一行搜索条件中选择“标题”或“任意字段”，输入例如 `graph neural networks`。
3. 按需填写起止年份，并选择来源支持的排序方式。
4. 点击“搜索发现”。

**核对结果：** 页面显示候选记录，包括标题、作者和出版信息。
可以展开摘要再决定是否导入。搜索无结果，表示这个外部来源没有返回符合本次条件的记录，与你的本地文献库是否为空无关。

## 增加条件或缩小范围

点击添加条件的按钮，为另一字段输入条件；来源支持时，可用 **AND（且）**、**OR（或）**、**NOT（排除）** 组合。
例如，标题包含一个主题，同时作者满足某个姓名。每行条件都需要输入搜索词，起始年份不能晚于结束年份。

OpenAlex 的 **OR** 只能连接相邻、同字段的条件。切换来源后，应重新核对可用字段和排序。
查询报错或没有结果时，先减少条件，再逐步增加限制。

## 预览并导入候选记录

单条候选点击“检查并导入”（Review and import）。批量处理时，先勾选候选，再点击“预览所选记录”（Review selected）。
每次最多选择 50 条，并且所选候选必须具有相同的标识符类型，才能放在同一次预览中。

应用会重新查找元数据并打开导入预览。检查准备出的记录和诊断，再点击“导入 … 条记录”。
搜索卡片与重新取得的元数据可能不同，应以本次预览为准。

**核对结果：** 预览显示“导入完成”，通过“查看已导入文献”可打开目标工作区中的新条目。
完整的预览规则见[导入文献](/zh-cn/guides/import/)。

## 常见中断点

| 现象 | 下一步 |
| --- | --- |
| 没有候选记录 | 减少条件、换字段、扩大年份范围，或更换来源 |
| 查询不受支持 | 检查该来源提供的字段、运算符和排序方式 |
| 已勾选候选，但文献库中没有条目 | 继续完成导入预览和确认 |
| 元数据预览失败 | 查看诊断；临时失败可重试，或用支持的标识符单独导入 |
