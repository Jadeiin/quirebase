title: 用键盘导航和整理文献

---

打开工作区的“文献库”，用快速导航切换位置，用结果列表和预览中的快捷键挑选文献。
下文的 `Mod` 在 macOS 上表示 ⌘ Command，在 Windows 和 Linux 上表示 Ctrl。

## 快速跳转到页面、工作区或项目

1. 点击“快速导航”，或点击文献库页面的空白处后按 `Mod+K`。
2. 在“搜索页面、工作区或项目”中输入名称，例如“项目”或某个工作区名。
3. 用 `↓`、`↑` 选择结果，按 `Enter` 打开，也可以直接点击结果。

输入文献关键词时，可选择“在文献库中搜索‘…’”，进入当前工作区的搜索结果。
打开其他工作区后，文献库和项目列表会切换到该工作区。

## 打开文献库的快捷键说明

点击文献库标题区域的键盘按钮，或按 `?`，打开“键盘快捷键”。
其中的“启用字母和符号快捷键”控制 `/`、`?`、`J`、`K`、`X`、`I` 等按键。
该偏好按账号保存在当前浏览器中。

| 按键 | 操作 |
| --- | --- |
| `/` | 聚焦文献库搜索框 |
| `?` | 打开快捷键说明 |
| `Esc` | 关闭当前弹层或预览，继续按可清除条目选择 |
| `Mod+Shift+C` | 调出所选或当前条目的引文复制操作 |

## 在结果列表中浏览和选择

用 `Tab` 将焦点移到一条文献的复选框，再使用以下按键：

| 按键 | 操作 |
| --- | --- |
| `↑` / `K` | 移到上一条文献 |
| `↓` / `J` | 移到下一条文献 |
| `Home` / `End` | 移到当前页的第一条或最后一条 |
| `Space` / `X` | 勾选或取消当前文献 |
| `Shift+X` | 将当前文献设为唯一选中项 |
| `Shift+↑` / `Shift+↓` | 向上或向下扩展选择范围 |
| `Mod+A` | 选择当前页的文献 |
| `I` / `Enter` | 从复选框打开当前条目的预览 |
| `Shift+F10` | 打开当前条目的操作菜单 |

在文献标题链接上按 `Enter` 可打开条目详情。鼠标操作时，也可按住 `Shift` 点击复选框来选择当前页的一段范围。

## 连续预览文献

打开预览后，把焦点保留在预览区域，用 `↑` / `K` 和 `↓` / `J` 查看前后文献。
预览会沿当前搜索结果继续到上一页或下一页；列表中的逐行浏览则在当前页内移动。
按 `Shift+F10` 打开预览条目的操作菜单，按 `Esc` 返回列表。

## 试一次：选择几篇文献并复制引文

1. 搜索出要整理的一组文献。
2. 用 `Tab` 聚焦第一篇目标文献的复选框，按 `X` 选中。
3. 用 `↓` 移动，再按 `X` 选择其他文献；连续范围可用 `Shift+↓`。
4. 焦点保持在选中的文献上，按 `Mod+Shift+C`，核对复制操作中的条目范围和格式。
5. 完成复制后，将结果粘贴到写作工具中。

引文格式和默认值见[导出指南](/zh-cn/guides/citations-and-exports/)。
