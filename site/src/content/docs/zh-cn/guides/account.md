---
title: 管理账号设置与凭据
description: 切换语言，检查浏览器会话，为程序创建、替换或撤销 API 令牌。
---

打开应用中的用户菜单，选择“账号设置”（Account settings）。即使没有活跃工作区成员关系，也可以使用账号级设置；
研究内容仍需要相应工作区访问权。

## 切换语言和浏览器偏好

在偏好区域选择“语言”，并设置是否默认折叠导航。应用语言与文档站顶部的语言选择器分别控制各自的显示。

“导出偏好”可以设置引文和文件下载默认值。这些设置保存在当前浏览器中，换设备前请阅读[导出说明](/zh-cn/guides/citations-and-exports/)。

## 修改密码

1. 在密码区域输入当前密码。
2. 输入至少 12 个字符的新密码。
3. 点击“修改密码”，核对返回状态。

无法登录时，应联系实例管理员了解账号恢复方式。新建另一个用户不会恢复原用户的成员关系、私人批注或作者记录。

## 检查并撤销浏览器会话

在会话区域查看创建时间、过期时间及“当前会话”标记。对于不再使用的设备，执行对应的撤销会话操作。
撤销当前会话或全部会话后，你会退出登录，需要再次登录才能使用浏览器应用。

浏览器登录会话与 API 令牌是两种凭据。要停止一个程序客户端，应撤销它的 API 令牌，不能只依赖浏览器退出登录。

## 创建 API 令牌

1. 在“API 令牌”（API Tokens）区域填写容易识别的名称，例如“文献整理脚本”。
2. 选择有效期，再点击“创建”。
3. 在一次性显示区域复制完整令牌，保存到目标客户端的凭据存储中。
4. 展开“客户端连接指南”（Client connection guide），查看本实例的 HTTP API 地址、OpenAPI 链接及 MCP 配置示例。
5. 让客户端通过 Bearer Authorization 请求头发送凭据，再验证能否列出工作区。

**核对结果：** 账号列表中出现带过期时间的令牌，客户端能够列出当前用户有权访问的工作区。
之后无法再从历史中取回明文令牌。

## 替换或撤销令牌

停止一个客户端时，在对应凭据旁点击“撤销令牌”。替换仍在使用的凭据时，先创建新令牌，更新客户端，验证成功后再撤销旧令牌。
如果明文丢失，直接创建替代凭据，不要尝试从历史找回。

令牌继承用户的当前权限，没有独立的只读或逐工具权限范围。
成员关系变化、过期、撤销和用户停用都会影响后续请求。不要把令牌放入 URL 查询参数，也不要把它发送给外部学术来源。

完整连接过程见 [HTTP API](/zh-cn/developers/http-api/) 和 [MCP](/zh-cn/developers/mcp/) 教程。
