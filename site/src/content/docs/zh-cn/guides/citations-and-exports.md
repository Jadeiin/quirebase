---
title: 导出引文、书目和文件包
description: 选择正确格式，核对选中的文献，并设置当前浏览器的导出偏好。
---

本页从“文献已经保存在文献库中”开始。先选择正确的工作区，再核对选中的条目，然后打开导出操作。

## 先确定需要什么输出

| 输出 | 适合什么任务 | 包含什么 |
| --- | --- | --- |
| CSL 引文（CSL citation） | 把排版后的参考文献复制到写作工具 | 使用可用 CSL 样式生成的文本 |
| BibTeX | BibTeX 写作流程 | 带引用键的书目数据 |
| RIS | 转到其他文献管理器 | 文献交换数据 |
| CSL-JSON | CSL 工具或结构化交换 | JSON 格式的引文元数据 |
| Commonmeta | 交换完整文献元数据 | 结构化书目信息，包括摘要和标识符 |
| 文件包 | 下载研究文件 | 所选 PDF 修订版及可选补充内容 |

## 导出一条文献

1. 打开条目，选择“导出”（Export）。
2. 在引文操作中选择格式。需要排版后的参考文献时选“CSL 引文”；准备导入其他管理器时选它支持的交换格式。
3. 需要更换 CSL 样式或其他偏好时，通过“导出设置”修改，再返回条目重新打开“导出”。
4. 选择“复制到剪贴板”或“下载文件”，生成结果。
5. 查看“引文文本”、粘贴到目标工具或打开下载文件，核对贡献者顺序、日期、标题和引用键。
   生成结果后想更换格式，可点击“修改选项”，选择新格式后重新导出。

浏览器拒绝剪贴板访问时，可以手动复制页面上的引文文本，或下载文件。

## 导出文献库中的一组条目

在文献库勾选目标行，再执行书目或文件操作。“选择本页”选中当前页，导出前可核对选中数量。

要导出某个项目的参考文献，先在文献库打开它的文献集合，核对项目筛选，再选择目标记录。
项目筛选决定导出哪些条目，输出格式决定元数据如何表达。

## 设置当前浏览器的默认值

打开“账号设置 → 导出偏好”：

1. 选择默认引文格式。使用 CSL 时，从有权访问的工作区目录中选择引文样式。
2. 核对排序、是否包含摘要、DOI/URL 策略及对应格式选项。
3. 准备下载文件包时，检查是否包含批注和补充文件。
4. 返回导出操作，在下载前检查实际选项。

这些偏好保存在当前浏览器中，并区分账号；引文样式的选择还区分工作区。
使用新浏览器或设备时，可在这里设置所需默认值。

字段排除只用于 BibTeX 和 CSL-JSON，必需的身份和类型字段会保留。Commonmeta 保留完整元数据。

## 查找或添加引文样式

打开“工具 → 引文样式”，搜索内置样式和工作区共享的自定义样式。
安装 CSL XML、设置默认值和验证排版的完整步骤，见[选择与共享引文样式](/zh-cn/guides/citation-styles/)。

“引用键”（Citation Key）用于在引文输出中标识条目；“引文样式”（Citation Style）决定排版格式。

## 下载带有所需上下文的 PDF

从条目“下载”操作选择 PDF 修订版，再执行文件包下载。核对页面显示的批注和补充文件偏好。
只需要一份 PDF，并希望明确选择哪些批注来源时，使用[阅读器的下载菜单](/zh-cn/guides/pdf-annotations/)。

**核对结果：** 文件包或 PDF 包含预期的修订版和批注来源。
