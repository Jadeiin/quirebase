---
title: 搜索与整理文献库
description: 查找已保存的文献，组合筛选，保存常用视图，并用标签和项目组织条目。
---

先进入准备查找的工作区，再打开“文献库”（Library）。文献库搜索覆盖已保存的条目元数据和本地 PDF 提取文本。
需要在线查询外部学术来源时，使用[发现](/zh-cn/guides/discovery/)。

## 找到一条已保存的文献

1. 在搜索框输入部分标题、作者、标签或正文中的词语。
2. 需要缩小范围时，展开“筛选”，选择标签、项目、有无文件、年份、贡献者或关键词。
3. 点击“搜索”，应用表单中的条件。
4. 核对结果上方已经生效的筛选标签。怀疑旧条件挡住了记录时，使用“清除筛选”。
5. 按需调整排序和每页数量，再打开条目或预览。

例如，想给尚未上传 PDF 的文献补文件，可以选择“文件 → 无文件”后搜索；想检查某个协作集合，可以按项目筛选。
各条件会一起缩小同一结果集。通过元数据控件选择多位精确作者时，条目需要同时匹配这些作者。

**核对结果：** 结果数量和当前筛选符合你的目的。从“查看已导入文献”进入时，可能还带着导入批次筛选。
切换工作区后，看到的也是另一个文献库。

## 保存一个常用视图

1. 先应用想重复使用的筛选、排序和每页数量。
2. 打开“已保存视图”（Saved views），输入例如“待补 PDF”，点击“保存当前视图”。
3. 下次从“已保存视图”中点击名称，即可重新运行这些条件。

视图保存在当前浏览器中，并区分账号和工作区。它保存查询设置，不是文献快照，也不是共享项目；换设备后不会自动同步。
重命名或删除视图不会修改、删除文献内容。

## 查看或编辑一个条目

打开条目后，按任务选择分区：

| 分区 | 用来完成什么 |
| --- | --- |
| 概览（Overview） | 阅读文献摘要信息，打开条目操作 |
| 元数据（Metadata） | 修正标题、按顺序排列的贡献者、标识符、类型、日期及引用键 |
| 文件（Files） | 添加或阅读 PDF 修订版和补充附件 |
| 整理（Organize） | 维护标签和项目关联 |
| 批注（Annotations） | 查看对你可见的批注和回复 |
| 讨论（Discussion） | 与有权限的工作区成员讨论这条文献 |

修改元数据后保存并核对结果。如果提示条目已被其他操作修改，先加载最新状态，检查后再重试。
“记录工具 → 元数据来源”提供按标识符更新的入口；来源信息也可能不完整，更新后仍应检查。

## 维护标签和项目关联

在“整理”中输入标签名并点击“添加标签”，也可以用现有标签控件改变关联。
标签是工作区共用的分类体系。来源关键词和推荐标签只有在你选择后，才会成为真正的条目标签。

在同一分区找到项目，点击“添加”。成功后应能看到该关联，并在项目中找到条目。
点击“移除”会解除关联，并永久删除这项关联的项目批注及回复；继续前请阅读确认信息。

需要处理多条文献时，在文献库中选中目标行，再使用可用的批量操作。选中条目不代表选中了整个文献库的所有搜索结果。
“选择本页”针对当前页；批量修改或导出前要核对选中数量。

## 检查疑似重复文献

打开“工具 → 重复条目检查”，选择“共享标识符”“相同标题”或“相同 PDF”，再点击“检查重复项”。
标题按完全相同的值比较，大小写和格式差异也会影响匹配；PDF 检查使用已就绪文件，较旧文件可能被跳过。

比较元数据、文件、项目上下文和批注后，再决定保留或删除哪条记录。系统不会根据建议自动合并条目。

## 复制到另一个工作区

打开条目的“复制到工作区”（Copy to Workspace），选择可用目标，点击“创建副本”，再通过“打开副本”核对目标条目及文件。

源工作区需要允许导出，目标工作区需要允许创建条目。副本拥有新身份和独立权限，后续编辑不会与原记录同步。
如果目的是在同一工作区内共同使用同一条目，应使用项目关联。

完成整理后，可继续[导出引文和文件](/zh-cn/guides/citations-and-exports/)。
