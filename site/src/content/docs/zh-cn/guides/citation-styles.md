---
title: 选择与共享引文样式
description: 查找排版样式、安装自定义 CSL XML，并将它用于文献导出。
---

引文样式决定作者、日期、标点和标题等元数据如何排版。
可以在工作区的样式目录中查找所需格式，也可以安装期刊的自定义 CSL 样式供同事使用。

## 查找样式

1. 在写作所用工作区中打开“工具 → 引文样式”。
2. 在“搜索引文样式”中输入期刊名或样式名称。
3. 用“来源”选择“内置”“自定义”或“全部来源”。
4. 按需调整名称排序，通过分页浏览结果。

内置样式由安装环境的 `citation` 可选依赖提供，Docker 镜像已包含该依赖。
自定义样式在当前工作区内共享。安装配置见[可选功能说明](/zh-cn/administration/configuration/)。

## 添加自定义 CSL 样式

准备好期刊或机构提供的 CSL 文件，打开“工具 → 引文样式”：

1. 点击“添加自定义引文样式”。
2. 填写易于辨认的“样式名称”，例如“实验室期刊 — 2026”。
3. 用文本编辑器打开 `.csl` 文件，将完整 XML 内容复制到“CSL XML”。
4. 点击“安装引文样式”。
5. 将“来源”设为“自定义”，搜索刚才的名称，核对目录中的结果。

每个自定义样式应使用不同名称。如果安装时提示 CSL 无效，检查粘贴内容是否包含文件的完整 XML 文档，修正后重试。

## 设为自己的默认导出样式

1. 打开“账号设置 → 导出偏好”。
2. 将“默认引文格式”设为“CSL 引文”，需要时切换到“CSL”标签页。
3. 在“引用样式所属工作区”中，选择查到或安装了目标样式的工作区。
4. 搜索名称，在“默认 CSL 样式”下选中它。

修改会随操作保存。当前浏览器按账号保存偏好，并分别记住各工作区所选的样式。
同事也可以从共享目录中选择适合自己的格式。

## 核对排版结果

1. 打开一条作者、标题和日期信息完整的文献，选择“导出”。
2. 选择“CSL 引文”，点击“复制到剪贴板”，生成参考文献。
3. 查看“引文文本”或将结果粘贴到写作工具，对照格式要求检查作者顺序、标点、大小写和期刊信息。
4. 想尝试其他样式时，通过“导出设置”修改偏好，返回条目重新导出。需要文本文件时，选择“下载文件”。

如果缺少作者或日期，先补全条目的“元数据”，再重新生成结果。
需要导出一组参考文献时，可继续使用[文献库批量导出](/zh-cn/guides/citations-and-exports/#导出文献库中的一组条目)。

“引用键”用于在 BibTeX 等格式中标识文献，例如 `smith2026reading`，可在条目的“元数据”中修改。
需要调整排版格式时，选择相应的 CSL 引文样式。

## 替换或移除自定义样式

发布修订后的样式时，先用不同名称安装新版本，验证输出，再到导出偏好中选用它。
同事准备好后，也可以切换到新版本。

停用旧样式时，在“来源 → 自定义”下找到它，点击“删除”，核对名称，再确认“删除样式”。
这会从工作区的共享目录中移除该样式。此前使用它的人，应在下次导出 CSL 引文前到“导出偏好”中选择替代样式。
