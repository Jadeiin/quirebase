title: 添加和管理文献文件
description: 选择主 PDF 或附件，等待处理，核对文件，并理解删除的范围。

本页从“条目已经存在”开始。希望用一批 PDF 创建新条目时，请先使用 [PDF 导入](/zh-cn/guides/import/)。
在条目所属工作区打开“文件”（Files）。管理文件和永久删除条目是不同的权限。

## 先选择正确的文件用途

| 你要添加什么 | 使用哪个区域 | 得到什么 |
| --- | --- | --- |
| 主文献 PDF，或修正后的主 PDF | 添加 PDF 修订 | 一个可独立处理、阅读的文件修订版 |
| 补充数据或其他支持文件 | 添加附件 | 与条目关联的附件 |
| 用作条目代表图的图片 | 添加附件，并勾选用作图形摘要 | 条目指定的图形摘要 |

一个条目可以有多份 PDF 修订版，每份都有各自的页面和批注。

## 上传并打开主 PDF

1. 在“添加 PDF 修订”（Add PDF revision）区域选择文件，点击“上传 PDF”。
2. 等待处理状态变为就绪。Worker 会检查 PDF，并提取文本和页面几何信息。
3. 在这份文件旁点击“阅读”。
4. 在阅读器中核对标题和文件名，确认打开的是预期文件。

有可直接下载的 PDF 地址时，使用 URL 添加区域，填写地址并执行下载添加。
地址应直接返回 PDF 文件，而不是需要在浏览器中跳转或登录的文章页面。下载文件与按标识符查找元数据是两种操作。

修正后的 PDF 会保存成另一份修订版，不会覆盖旧文件，也不会迁移旧批注。仍需旧批注或页码引用时，应保留旧修订版。

## 添加附件或图形摘要

在“添加附件”中选择补充文件，再点击“上传附件”。添加代表图片时，应在上传前勾选“用作图形摘要”。
可直接下载的远程补充文件也可以通过 URL 附件表单添加。

**核对结果：** 文件列表中出现了预期文件及用途。一个条目最多指定一份图形摘要，它会优先于自动生成的 PDF 首页缩略图用于展示。
普通附件不会变成阅读器中的主 PDF 修订版。

## 读懂处理状态

| 状态 | 含义 | 下一步 |
| --- | --- | --- |
| 等待或处理中（pending） | 正在排队或检查文件 | 保持 Web 和 Worker 运行；长期不变时检查 Worker |
| 就绪（ready） | 提取完成 | 点击“阅读”并核对文件 |
| 失败（failed） | 检查失败，但源文件仍保留 | 查看错误并使用“重试处理”，或上传修正后的 PDF |

当前不支持加密 PDF 和 OCR。纯扫描图片 PDF 可能可以显示，但没有可搜索的提取文本。
PDF 和附件的默认单文件上限为 250 MiB，运维配置或反向代理可能使用其他上限。
遇到大小错误时应核对实际限制，不要反复重传同一份超限文件。

## 下载或删除文件

文件旁的“下载”返回保存的文件内容。要把批注写入导出 PDF，应打开具体修订版，再使用
[下载含标注的文件](/zh-cn/guides/pdf-annotations/)。条目的文件下载操作还可以把所选修订版组成文件包。

点击“删除”前，先核对具体修订版或附件，并保存需要保留的副本。
删除 PDF 修订版会删除依附其上的批注及派生缩略图；删除附件会移除该补充文件。
永久删除整个条目则会移除其关联文件和上下文。这些操作的影响范围不同。
