---
title: 导入文献和 PDF
description: 选择导入方式，读懂预览，并确认哪些记录和文件真正写入文献库。
---

先打开目标工作区，再进入“导入”。你需要有创建条目的权限。
如果手头只有主题、标题或作者，请先阅读[搜索外部来源](/zh-cn/guides/discovery/)。

## 根据手头材料选择方式

| 标签页 | 适用输入 | 什么时候创建条目 |
| --- | --- | --- |
| 标识符列表 | DOI、PMID、arXiv、ISBN、OpenAlex 标识符或支持的标识符链接 | 检查预览并确认后 |
| 书目 | BibTeX、RIS、CSL-JSON、Commonmeta 数据 | 检查预览并确认后 |
| PDF 文件 | 最多 50 份 PDF，希望从中识别元数据 | 确认预览后；无元数据 PDF 还需单独勾选 |
| 手工创建 | 直接填写一条记录 | 点击编辑器中的“创建条目”时 |

前三种方式先生成“导入批次”（Import Batch）供检查，手工创建则直接保存条目。

## 用标识符导入

1. 选择“标识符列表”，每行输入一个标识符，最多 50 个。例如：

   ```text
   10.1073/pnas.92.6.2288
   https://pubmed.ncbi.nlm.nih.gov/11607519/
   arXiv:2304.08030
   ISBN:0674016394
   ```

2. “数据来源”保持“自动检测”，或选择支持这些输入的来源。
3. 点击“预览元数据”，再按下文检查预览。

ISBN-10 使用 `ISBN:` 前缀。需要搜索 PMC 文章时，可使用[发现](/zh-cn/guides/discovery/)。

## 导入书目文件或粘贴的数据

1. 选择“书目”。
2. 点击文件选择按钮上传文件，或在粘贴区域输入书目数据。已选择文件时，要先移除该文件才能改用粘贴输入。
3. “文件格式”保持“自动检测”；检测不准确时再指定格式。
4. 点击“预览书目”。

从原文献管理器导出 BibTeX、RIS、CSL-JSON 或 Commonmeta 文件，使用 UTF-8 编码，大小最多 5 MiB。

## 导入 PDF

1. 选择“PDF 文件”，拖入或选择文件，最多 50 份。
2. 点击“预览导入”。候选记录由 Worker 在后台准备，可以稍后从保留的预览继续。
3. 分别检查“已识别的文献”和“未识别元数据的 PDF”区域。
4. 对于无元数据的基础 PDF 候选，逐一勾选想保留的文件，或使用该区域的“全选”。

选中的基础 PDF 会以最少的元数据保留文件，导入后可以补充信息。文件准备见[文件管理](/zh-cn/guides/files/)。

## 看清预览，再确认一次

检查标题、贡献者、文献类型、标识符、出版信息及“导入问题”。在线来源的元数据可能不完整。

| 预览内容 | 确认时的行为 |
| --- | --- |
| 已识别记录 | 准备好的已识别记录会整批导入 |
| 无元数据的基础 PDF | 只导入你明确勾选的基础 PDF 候选 |
| 诊断或失败信息 | 说明被跳过或暂不可用的输入；成功候选仍可导入 |

需要调整已识别记录时，点击“丢弃”，修正输入后重新生成批次。临时来源错误可使用页面提供的“重试元数据”。

批次就绪后，先核对“导入 … 条记录”按钮上的数量，再确认。出现“导入完成”后点击“查看已导入文献”。
此时文献库会按本次导入批次筛选；需要查看其他文献时，应清除这项筛选。
文件处理和标签推荐可能在确认后继续执行。

## 稍后继续，或核实不确定的结果

通过“导入历史”可以重新打开保留期内的批次。如果页面提示无法确认导入是否完成，点击“检查导入状态”查看结果。

对已提交批次使用“删除导入记录”，会保留条目和文件，但不再保留确认回执及对应的文献库批次筛选。
批次和导入历史的保留期由实例设置决定。
