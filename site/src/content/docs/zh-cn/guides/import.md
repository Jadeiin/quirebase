---
title: 导入文献和 PDF
description: 预览标识符、书目数据或 PDF，在确认后写入工作空间。
---

先选择目标工作空间，再打开 **Import（导入）**。导入需要创建 Item（条目）的权限。

| 来源 | 支持的输入 |
| --- | --- |
| Identifiers（标识符） | 最多 50 个支持的标识符或标识符链接，每行一个 |
| Bibliography（书目） | UTF-8 文件或粘贴的 BibTeX、RIS、CSL-JSON、Commonmeta 数据，最大 5 MiB |
| PDFs | 用于准备候选元数据的 PDF 文件 |
| Manual creation（手动创建） | 在元数据编辑器中直接填写信息 |

## 使用标识符查找元数据

保持 **Auto detect（自动检测）**，或选择可用的 Provider（数据来源）。例如：

```text
10.1073/pnas.92.6.2288
https://pubmed.ncbi.nlm.nih.gov/11607519/
arXiv:2304.08030
ISBN:0674016394
```

ISBN-10 需要加上 `ISBN:` 前缀，以区别于 PubMed ID。普通网页或文章落地页的 URL 不支持元数据查找；
请使用支持的标识符或手动创建。当前不支持 PMCID 查找，但可以通过 PMC 进行在线发现。

## 检查预览，再确认导入

准备操作会创建 Import Batch（导入批次），保存候选记录和诊断信息，但不会创建条目。
检查标题、贡献者、出版信息及选中的候选记录后再确认。在线来源的元数据可能不完整。
确认后，所选条目才会写入目标工作空间；文件处理和标签推荐可能继续在后台运行。

部分输入失败不会使成功的候选记录失效。刷新预览页面仍可查看已准备的批次。
遇到临时元数据错误时，可以使用页面提供的 **Retry metadata（重试元数据）**。

对于未识别元数据的 PDF，需要显式选中想保留的基础 PDF 候选记录，导入后再补充元数据。
当前不支持加密 PDF 和 OCR。

## 通过 Discovery 在线发现文献

只有标题、作者或主题时，打开 **Discovery（发现）**。选择来源，填写条件，并使用该来源支持的
年份过滤、排序和分页。支持时可组合 **AND**、**OR**、**NOT**；OpenAlex 的 **OR** 仅能连接相邻的同字段条件。

选择发现结果会将其准备为导入候选，仍需检查并确认，才会成为条目。
Discovery 查询外部来源；[Library Search（资料库搜索）](/zh-cn/guides/library-management/)
查询工作空间内已经保存的条目和 PDF 提取文本。

## 管理导入历史

在导入历史中返回保留的预览，或查看已确认批次创建的条目。使用 **Discard（放弃）** 可以丢弃未确认的批次。
删除已确认的导入记录会保留条目和文件，但不再保留该批次的确认结果及资料库中的批次过滤入口。

导入批次是临时记录，会按实例配置的保留期限清理，不能作为源文件的长期备份。
运维说明见[备份、升级与恢复](/zh-cn/administration/maintenance/)。
