---
title: 用标签整理文献
description: 为文献添加标签、浏览同一主题，并维护工作区共用的分类名称。
---

标签适合组织跨项目的分类，例如“研究方法”“数据集”“待读”。先进入存放目标文献的工作区。

## 给一条文献添加标签

1. 打开条目，进入“整理”。
2. 在“标签矩阵”中查找已有标签。可以用“筛选标签”缩小列表，再点击标签名。
3. 需要新分类时，在“条目标签”下输入名称，点击“添加标签”。
4. 在“条目标签”中核对已分配的名称。

例如，给刚导入的文献添加“待读”。读完后，点击“条目标签”中该名称旁的“×”，即可解除这条文献的标签关联。
其他文献仍可继续使用这个标签。

新标签名可包含 1–120 个字符。Quirebase 会整理空白字符；名称只有大小写差异时，会沿用已有标签。
与同事约定少量常用分类，有助于保持共享目录清晰。

## 使用标签推荐

“标签推荐”根据文献元数据和最新已就绪 PDF 提供建议。点击带“+”的建议，将它分配给当前条目。
“标签矩阵”中名称旁的“★”表示推荐使用的已有标签，点击名称即可应用。

更新元数据或添加 PDF 后，可在“标签推荐”中点击“刷新”，请求重新生成建议。
处理完成后，选择适合这条文献的名称。

## 找到同一标签下的文献

1. 打开“工具 → 标签”。
2. 在“筛选标签”中输入部分名称。
3. 找到标签，点击“查看条目”。
4. 在文献库中核对已生效的标签筛选，再阅读匹配的文献。

可以继续组合项目、年份或文件筛选。经常使用的条件可以[保存为文献库视图](/zh-cn/guides/library-management/#保存一个常用视图)。

## 重命名共享标签

在“工具 → 标签”中，点击目标标签旁的“重命名”，填写“新标签名称”，再确认“重命名”。
工作区中所有使用该标签的条目都会显示更新后的名称。

如果想用的名称已经存在，可以合并两个标签，统一它们关联的文献。

## 合并两个标签

例如，团队先后使用了“机器学习”和“ML”，现在想统一保留“机器学习”。在“工具 → 标签”中找到“合并标签”：

1. “来源标签”选择准备停用的“ML”。
2. “目标标签”选择准备保留的“机器学习”。
3. 核对合并方向后，点击“合并标签”。合并会立即执行。
4. 找到“机器学习”，点击“查看条目”，检查合并后的文献集合。

目标标签会接收来源标签的全部关联，同时带有这两个标签的文献也会归入同一集合。
来源标签会被删除。使用过来源标签的已保存视图，可改为目标标签后重新保存。

## 停用一个标签

在“工具 → 标签”中点击目标标签旁的“删除”，核对名称，再确认“删除标签”。
这会删除工作区内的共享标签及其条目关联，文献记录继续保存在文献库中。
若只想从某一条文献移除标签，在该条目的“条目标签”中点击“×”即可。
