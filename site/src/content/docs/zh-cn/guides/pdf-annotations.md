## 打开文件修订版

在条目的 **Files（文件）** 中选择已就绪的主 PDF。每个 File Revision（文件修订版）都是不可变的 PDF 版本：
检查期间为 pending，提取成功后为 ready，失败时为 failed，并保留源文件供重试。
补充文件是 Attachment（附件），与主 PDF 修订版不同。

批注绑定一个文件修订版的具体页面。上传另一个修订版不会迁移已有批注。
添加文件和恢复处理错误的方法见[文件管理](/zh-cn/guides/files/)。

## 选择新批注保存到哪里

在阅读器中打开 **Annotations（批注）**：

1. 在 **Displayed annotation sources（显示的批注来源）** 下，选择要查看的私人批注和项目批注。
2. 在 **Save new annotations to（将新批注保存到）** 下，选择 **Private annotations（私人批注）** 或可编辑的项目。
3. 使用阅读器工具创建标记和笔记。
4. 离开页面前检查保存状态。如果显示保存失败，先处理错误再刷新。

显示的来源与新批注的保存目标是两个独立设置。显示项目批注，不会让新建的私人批注变成共享批注。
一条 Annotation（批注）的私人或项目可见范围在创建时固定；需要面向其他读者创建批注时，请先切换保存目标。

批注回复继承原批注的可见范围。条目讨论和项目讨论是独立对话，不绑定 PDF 页面坐标。

:::caution[从项目移除条目]
移除 Project–Item 关联，会永久删除该关联的项目批注及回复。工作空间中的原始条目、文件、私人批注及其他项目关联仍保留。
移除前请与协作者确认需要保留的内容。
:::

## 下载 PDF

- **Download → Download original（下载原文件）** 返回原始文件修订版。
- **Download → Download with annotations（下载带批注文件）** 根据已显示且有权读取的批注来源，生成临时 PDF。

导出不会改动保存的原文件。请在导出产物过期前下载；过期后可重新生成。
当前不支持扁平化批注导出、加密 PDF 和 OCR。

遇到处理、保存或下载错误时，请参阅[故障排查](/zh-cn/knowledge-base/troubleshooting/)。
