## 根据你的情况选择入口

| 你现在要做什么 | 从这里开始 | 完成后得到什么 |
| --- | --- | --- |
| 团队已经有 Quirebase，我刚开始使用 | [添加第一条文献](/zh-cn/getting-started/quickstart/) | 一个已保存的条目、可阅读的 PDF 和私人批注 |
| 手头有 DOI、书目文件或一批 PDF | [导入文献](/zh-cn/guides/import/) | 已检查并确认写入工作区的导入结果 |
| 只有主题、标题或作者，想在线找文献 | [搜索外部来源](/zh-cn/guides/discovery/) | 可以进一步预览和导入的候选记录 |
| 想在已有文献中查找和分类 | [搜索与整理文献库](/zh-cn/guides/library-management/) | 筛选结果、标签或已保存视图 |
| 想用键盘快速挑选文献和复制引文 | [键盘导航与整理](/zh-cn/guides/keyboard-shortcuts/) | 页面跳转、条目选择和引文复制流程 |
| 想与同事一起阅读、讨论 | [项目协作](/zh-cn/guides/collaboration/) | 项目中的文献集合和共享批注 |
| 想记录阅读问题或安排共读 | [文献与项目讨论](/zh-cn/guides/discussions/) | 同事可接续的讨论消息 |
| 负责部署和维护实例 | [部署 Quirebase](/zh-cn/administration/deployment/) | 数据持久化、Web 和 Worker 正常运行的实例 |

## 按一次完整工作流程阅读

1. [选择工作区并添加文献](/zh-cn/getting-started/quickstart/)。
2. [添加 PDF 修订或附件](/zh-cn/guides/files/)。
3. [阅读、批注，并确认保存成功](/zh-cn/guides/pdf-annotations/)。
4. 需要共读时，[把条目加入项目](/zh-cn/guides/collaboration/)。
5. 写作时，[导出引文、书目或文件包](/zh-cn/guides/citations-and-exports/)。

正文中的“条目（Item）”指一条文献记录，“文件修订版（File Revision）”指关联的一份主 PDF。
工作区（Workspace）决定谁能访问文献库；项目（Project）组织该工作区内的一组协作文献。
[核心概念](/zh-cn/concepts/research-library/) 用一个例子解释它们的关系。

## 遇到问题时

导入一直等待、PDF 处理失败、找不到操作按钮、批注没有保存，都可以从[故障排查](/zh-cn/knowledge-base/troubleshooting/)开始。
[常见问题](/zh-cn/knowledge-base/faq/)解释权限、共享和删除的影响。

本文档介绍 Quirebase 当前开发版本。[API 参考](/reference/api/)由 FastAPI Schema 自动生成，接口说明使用英文。
